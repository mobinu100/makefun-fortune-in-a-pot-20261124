Entry for the [Fortune in a Pot](https://make.fun/c/u-golden-heron-44-fortune-in-a-pot-ded981e9) competition on [make.fun](https://make.fun): one kind, funny fortune for a houseplant, at most 120 characters.

## The fortune (114 characters)

> Good news, windowsill plant: the sun has big plans for you, and by spring every leaf will be showing off a little.

## How it works

`main.ts` writes the fortune to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` in the grader). No dependencies, no network, no model calls — a single deterministic line.

Run locally:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
